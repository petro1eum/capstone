# Published café-count report

Public site: https://petro1eum.github.io/capstone/

This branch contains the standalone HTML report, its eight-page PDF, and a share-preview image.
GitHub Pages publishes the `gh-pages` branch, root directory, without Jekyll.

Source analysis: https://github.com/petro1eum/capstone/tree/a7b1bfc2caf6a2663d593a002300ea25bdf78ca1
Data snapshot: 2026-09-28. Validation: 50 repeated nested spatial splits.

The report predicts recorded counts and provides a fieldwork shortlist. See the report for
its source-comparability and business-inference limitations. Data attribution is retained there.

To update, regenerate `report/report_ru.html` from the reviewed source analysis, export its PDF,
then replace `index.html`, `report.pdf` and `share.png` on this branch. Preserve the relative PDF link,
canonical URL and share metadata. `site.json` records the deployed source and SHA-256 file hashes.
